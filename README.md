# UI-UX-CSC
# Emergency Response & Disaster Coordination Platform  
UI/UX Design Challenge – Round 1 (UI & Wireframing)

---

## 📌 Problem Understanding
During emergencies and natural disasters, affected individuals struggle to communicate urgent needs such as medical help, food, or shelter. At the same time, responders face challenges like damaged infrastructure, information overload, and rapidly changing priorities.

This platform aims to provide a structured way for victims to raise emergency requests and for responders to view, prioritize, and act on those requests efficiently.

---

## 👥 Target Users
### Primary Users
- Affected individuals (victims)
- Emergency responders (rescue teams, NGOs, authorities)

### Secondary Users
- Admin / Control center (for coordination and monitoring)

---

## 🎯 User Goals
### Victims
- Report emergencies quickly
- Request specific help (medical, food, rescue, shelter)
- Track request status

### Responders
- View incoming emergency requests
- Prioritize requests based on urgency
- Track ongoing and resolved cases

---

## 🔄 User Flow
1. User lands on the platform
2. Victim selects “Report Emergency”
3. Victim fills emergency request form
4. Request is submitted successfully
5. Responder logs in
6. Responder views emergency dashboard
7. Responder checks request details
8. Request is marked as “In Progress” or “Resolved”

---

## 🧱 Wireframe Scope (Low–Mid Fidelity)
The wireframes focus on **layout, navigation, and structure**, not visual styling.

### Screens Designed
- Landing Page
- Emergency Reporting Form (Victim)
- Submission Confirmation Page
- Responder Dashboard
- Emergency Request Details Page

---

## 🧩 Key Features (Wireframe Level)
- Simple navigation for quick access
- Emergency request form with basic fields
- Dashboard layout for responders
- Status indicators (Pending / In Progress / Resolved)
